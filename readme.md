# Memória Descritiva

Para este seguinte trabalho foi necessário a recriação do quadro de Mondrian mas com uma leve desordem utilizando o random()
Como elemento generativo que escolhi foi randomizar a linha que se encontra por de baixo do retângulo vermelho. O que fiz foi deixar a linha no canto esquerdo e colocá-la a tremer. Escolhi fazer isto porque acho que as linhas são algo muito predominante na pintura de Mondrian e acaba por trazer um certo desequilibrio e uma instabilidade para a obra, já as linhas fixas traziam-me estabilidade ao observar este quadro.
